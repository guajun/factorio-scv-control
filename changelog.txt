---------------------------------------------------------------------------------------------------
Version: 0.1.0
Date: 29. 08. 2026
  Features:
    - Added right-click movement commands for the player character.
    - Added Shift + right-click command queueing.
    - Added asynchronous pathfinding, path visualization, and stuck recovery.
    - Added per-player queue limit and path visibility settings.
    - Added English and Simplified Chinese localisation.
    - Added an isolated local Factorio load and lifecycle test harness.
    - Added a reusable interactive test scenario and local save generator.
    - Added automatic structured planner logging in the interactive test scenario.
    - Added modular production runtime components shared by the local headless TestKit.
    - Added an agent-facing smoke and integration runner with JSON reports and reliable exit codes.
    - Made integration success depend on completed movement and queue tasks instead of a fixed tick window.
    - Added a trajectory planner that decomposes arbitrary segments into hysteresis-controlled native movement vectors.
    - Added per-tick follower traces and engine-backed direction calibration in the local TestKit.
  Bugfixes:
    - Fixed fast characters overshooting waypoints and repeatedly replanning around phantom obstacles.
    - Fixed old path renderings overlapping the current plan and appearing as a single detour.
    - Optimized extreme non-minimal paths returned by the engine pathfinder using sequential near and fallback alternate vias.
    - Fixed alternate routes overshooting the nearer end of long obstacles when the fallback via was unnecessarily far away.
    - Removed collision-safe grid zigzags and endpoint reversals from engine paths before following them.
